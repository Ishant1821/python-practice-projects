# Python Loop Control Statements

A foundational reference script demonstrating how to control loop execution using `break`, `continue`, and `pass` in Python.

## Concepts Covered

* **`break`**: Immediately terminates the nearest enclosing loop.
* **`continue`**: Skips the remainder of the current loop iteration and moves to the next.
* **`pass`**: Acts as a null operation/placeholder when syntax requires a statement but no action is needed.
* **`while True` with `break`**: Standard pattern for interactive or event-driven infinite loops.
