# 🧮 Simple Python Calculator

A command-line calculator built with Python that performs basic arithmetic operations based on user input.

---

## 💡 Features

* **Addition (`+`)**
* **Subtraction (`-`)**
* **Multiplication (`*`)**
* **Division (`/`)**
* **Floor Division (`//`)**
* **Exponentiation (`**`)**
* **Average Calculation**
* **Modulus / Remainder (`%`)**

---

## 🛠️ Concepts Covered

* **User Input Handling:** Reading strings and casting to integers/floats.
* **Control Flow:** Conditional evaluation using `if`, `elif`, and `else`.
* **Arithmetic Operators:** Standard Python mathematical operators (`+`, `-`, `*`, `/`, `//`, `**`, `%`).
